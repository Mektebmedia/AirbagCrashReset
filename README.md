# AirbagCrashReset.nl — Landingspagina

Premium landingspagina voor airbag crash data reset service. Gebouwd met pure HTML, CSS en JavaScript.

## 🚀 Kenmerken

- **Dark premium design** — geïnspireerd op carlabimmo.com
- **Volledig responsive** — mobiel, tablet en desktop
- **Glassmorphism effects** — moderne UI styling
- **Animaties & micro-interacties** — scroll reveal, counters, FAQ accordion
- **SEO geoptimaliseerd** — Schema.org markup, meta tags, canonical URLs
- **WhatsApp integratie** — Floating action button + header/footer links
- **Contactformulier** — met validatie en feedback
- **Geen externe afhankelijkheden** — pure HTML/CSS/JS

## 📁 Structuur

```
AirbagCrash/
├── index.html      # Hoofdpagina
├── style.css       # Alle stijlen (dark theme, responsive)
├── main.js         # Interactiviteit (menu, FAQ, animaties)
├── hero-airbag.jpg # Hero afbeelding
└── README.md       # Dit bestand
```

## 🎨 Design systeem

- **Primaire kleur**: `#e85d04` (oranje)
- **Achtergrond**: `#0d0f14` (dark)
- **Font**: Poppins + Montserrat (Google Fonts)
- **Stijl**: Glassmorphism, dark mode, premium

## 📱 Secties

1. **Hero** — H1 met CTA en animaties
2. **Stats bar** — Animated counters
3. **Werkwijze** — 4-stappen uitleg
4. **Waarom wij** — USP's + feature cards
5. **Merken** — Alle ondersteunde automerken
6. **Prijzen** — Transparante tarieven
7. **FAQ** — Veelgestelde vragen (accordion)
8. **Contact** — Formulier + contactgegevens
9. **Footer** — Links en bedrijfsinfo

## 🛠️ Gebruik

Simpelweg `index.html` openen in een browser of hosten op een webserver.

Voor het contactformulier: vervang de simulatie in `main.js` door een echte endpoint (bijv. Web3Forms, Formspree, of eigen backend).
